Why Chalk

A sketch recogniser that fits anywhere

No server, no API key, no per-request bill. A small Kotlin library that you can read, test and ship.

Reads strokes

Pass the points the finger drew, straight from your canvas. Size and position on screen don't matter; the drawing is simplified on the device the same way the training data was.

Guesses while you draw

Trained on half-finished drawings too, so it can guess after the first strokes, like the Quick, Draw! game. It beats a 200× larger model there.

No dependencies

Pure Kotlin inference. There is no ONNX Runtime, TFLite, ML Kit or native code, and it runs on Android (minSdk 21), iOS, macOS, JVM desktop, JavaScript and WebAssembly, from Kotlin or Java.

Private & offline

The model ships inside the library on every platform. It makes no network calls, needs no permissions and sends no telemetry.

Install

Add it to your build

One line in your Gradle file, from Maven Central. Works in commonMain for Android, iOS, macOS, JVM desktop, JavaScript and WebAssembly. No API key, no account.

Maven Central live
// build.gradle.kts: commonMain, or any platform source set
dependencies {
    implementation("io.github.rajumark:chalk:2.0.0")
}

// Gradle picks the right artifact per platform:
// chalk-android · chalk-jvm · chalk-iosarm64 · chalk-iossimulatorarm64
// chalk-macosarm64 · chalk-js · chalk-wasm-js
Build with a prompt
Add Chalk from rajumark to this Kotlin Multiplatform or Android project.

What it does: on-device doodle recognition. Given the pen strokes of a drawing (screen pixels), it returns the most likely of 345 everyday things (the Quick, Draw! categories), even for half-finished drawings. 1.7 MB, no dependencies, no network.

Install (Maven Central, no extra repository):
  build.gradle.kts (commonMain or any source set): implementation("io.github.rajumark:chalk:2.0.0")
  Platforms: Android, iOS, macOS, JVM desktop, JavaScript, WebAssembly

Usage:
  val chalk = Chalk()                         // off the main thread, keep one instance
  val strokes = listOf(Stroke(xs, ys), ...)          // one Stroke per finger-down ... finger-up
  val guesses = chalk.guess(strokes)                 // [Guess(label=house, score=0.89), ...]

Repo: https://github.com/rajumark/chalk#readme

Usage

One call per stroke

Load once and reuse the instance. guess() is thread-safe; call it after every stroke to guess live.

Kotlin
val chalk = Chalk()

val strokes = mutableListOf<Stroke>()
// on every finger-up:
strokes += Stroke(xs.toFloatArray(), ys.toFloatArray())
chalk.guess(strokes)
// [Guess(label=house, score=0.89), Guess(label=barn, score=0.06), ...]

chalk.guess(strokes, count = 5)
chalk.close()
Java
try (Chalk chalk = new Chalk()) {
    List<Guess> guesses = chalk.guess(strokes);
    String best = guesses.get(0).getLabel();
}

Reference

API at a glance

MemberDescription
Chalk()Loads the bundled model. Implements AutoCloseable.
guess(strokes, count = 3)The count most likely labels, best first, as Guess(label, score). Empty for no points.
probabilities(strokes)A probability for every label, in the order of labels; null for no points.
labelsThe 345 labels, as Quick, Draw! names them.
Stroke(x, y) · Stroke.of(x0, y0, …)One stroke: the points from finger-down to finger-up, in any coordinates.

FAQ

Questions

What is Chalk?

A Kotlin Multiplatform library (Android, iOS, macOS, JVM desktop, JavaScript, WebAssembly) that recognises doodles: give it the strokes of a drawing and it guesses which of 345 everyday things it shows.

Which things does it know?

The 345 categories of Google's Quick, Draw!: animals (cat, dog, lion, fish …), food (pizza, banana, cake …), vehicles, household objects, shapes, body parts and landmarks like The Eiffel Tower. chalk.labels lists them all. Anything else gets the nearest of these.

Do I need to send an image?

No. Chalk reads strokes, the points a finger or stylus draws. It is much smaller and faster than an image model, and it knows the order the lines were drawn in, which is what lets it guess early.

Can it guess before the drawing is finished?

Yes. It was trained on half-finished drawings too. Call guess() after every stroke, or every few points while the finger moves.

How fast is it on a phone?

A few milliseconds on a laptop JVM, and in the same speed class as Hoverfly's other libraries on an Android emulator. Load it once, off the main thread, and call it from a background thread.

Is the Kotlin port exact?

From screen-like float coordinates, the simplified points, the top-3 guesses and the probabilities (within 0.000002) match the reference implementation on all 150 test drawings, on the JVM and on an Android device.

How much does Chalk cost?

Nothing for products with up to 10,000 monthly active devices per platform, including commercial apps. There is no API key or account, and no limit on how often it runs. Above that, a commercial license is needed; see Pricing.
